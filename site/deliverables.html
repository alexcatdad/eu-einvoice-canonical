Deliverables

The interface is the product: the types, the schemas, the HTTP API, the command line and the evidence behind them. Each one is generated from the same TypeScript sources, so they cannot drift apart.

Versions: package {{PACKAGE_VERSION}}, JSON Schema {{SCHEMA_VERSION}}, HTTP API /{{SCHEMA_VERSION}}. See Deliverables and versioning for the compatibility promise.

  • TypeScript types and library

    convert(), inspect(), detectXml() and the CanonicalInvoice model, with the BT/BG ids in the comments. ES modules, no native code; runs in Bun, Node 20+ and browsers.

  • HTTP API (OpenAPI 3.1)

    POST /v1/convert, /v1/inspect, /v1/detect, GET /v1/formats, /v1/schemas/{name}. Errors are RFC 9457 problems in the CLI's exit-code categories. Run it with einvoice serve or the Dockerfile.
