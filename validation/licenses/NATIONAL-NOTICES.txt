NLCIUS and the Dutch G-account extension
--------------------------------------
Copyright (c) 2017 Stichting Simplerinvoicing. The pinned Dutch authority
repository MIT license is retained in each bundle's licenses/MIT.txt. The
native CII rules and the EN16931 material in the G-account suite also carry
EUPL-1.2 notices; the full license is retained in licenses/EUPL-1.2.txt.
Original Schematron sources are included. The G-account bundle also includes
the original compiled XSLT and its Schematron include closure. The standalone
native UBL/CII patterns are wrapped in namespace-declaring schema elements by
scripts/build-validation-bundles.ts, without changing their rules. No generic
EN rule set is substituted for the G-account publisher's modified suite.

Romanian CIUS-RO 1.0.9 integrated UBL rules
----------------------------------------
The authority's integrated top-level schema and included EN16931 material state
EUPL-1.2. Full license text, original source closure and derived source are
retained beside the compiled artifact. The documented build adapter expands
publisher patterns and retains attribute rule contexts. It does not change the
publisher's national replacement of BR-27 or add a second generic EN suite.
https://mfinante.gov.ro/static/10/eFactura/ro16931-ubl-1.0.9.zip

For all compiled bundles, the repository's build-validation-bundles.ts and its
referenced adapters provide the build instructions and transformations. Original
and derived file hashes are recorded in bundle manifests. Corresponding source
files and license notices must accompany redistribution of these bundles.
